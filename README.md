# AdrianMod

This is a Terraria mod for my most goated HUB O.
Now you get to fight him in Terraria as a boss.
(100% lore accurate, I've seen him do all these moves irl)

## ⚠️ IMPORTANT
**THIS MOD DOES NOT WORK IN MULTIPLAYER**

## Download
Find the latest `.tmod` file under the **Releases** tab on the right side of this page.

## Installation
1. Download the `.tmod` file (In 'R')
2. Place it in your tModLoader mods folder: `Documents\My Games\Terraria\tModLoader\Mods`
3. Launch tModLoader
4. Go to **Mods** from the main menu
5. Find **AdrianMod** and enable it
6. Reload mods
7. You're in

## Summoning
Craft the **IPPT Gold** at an Ancient Manipulator:
- 1x Celestial Sigil
- 1x Gold or Platinum Bar

Use the sigil anywhere. Good luck.

## Notes
- Recommended to fight post-Moon Lord
- Bring your best gear
- It won't be enough
